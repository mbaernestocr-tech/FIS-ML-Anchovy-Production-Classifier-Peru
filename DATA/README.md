# DATA: files of the reported run

Files used and produced by the notebooks of this repository (run 20260903_19h_54m_23s).

- DS_DGSF_DESCARGAS_anonimizado.csv: individual anchovy landing records. Source: Ministerio de la Produccion (PRODUCE), Open Data Portal of Peru (https://www.datosabiertos.gob.pe/sites/default/files/DS_DGSF_DESCARGAS_anonimizado.csv). License: Open Data Commons Attribution License.
- EXALMAR_EXALMC1_LM_OHLC_diario.csv and AUSTRAL_AUSTRAC1_LM_OHLC_diario.csv: daily prices (OHLC) of EXALMC1 and AUSTRAC1 listed on the Bolsa de Valores de Lima, with technical indicators computed by the authors. They are used only by the liquidity diagnosis and the exploratory backtest of the main notebook.
- results_v6_20260903_19h_54m_23s.json: results file of the reported run, produced by the main notebook. Every figure quoted in the manuscript is traceable to a key of this file.

The HadCRUT5 temperature file is not stored here: the main notebook downloads it from the Climatic Research Unit (University of East Anglia).
